# SKY DASH 3D

A complete frontend-only endless runner built with HTML5, CSS3, vanilla JavaScript, Canvas and localStorage.

## Run
Open `index.html` directly in Chrome or Edge. No server, Node.js, database or installation is required.

## Controls
- A / Left: lane left
- D / Right: lane right
- W / Up / Space: jump
- S / Down: slide
- Shift: boost
- P: pause
- R: restart
- Mobile: on-screen controls

## Systems
Endless pseudo-3D runner, 3 lanes, obstacles, collectibles, powerups, combo, XP/levels, heroes, skins, trails, shop, upgrades, missions, achievements, worlds, daily challenge, leaderboard, settings, themes, Web Audio effects, particles, day/environment effects, localStorage persistence and responsive mobile UI.

## Storage
Progress is stored in one localStorage object named `skyDash3D`.
